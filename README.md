# RELIEFF — Arhitectură în piatră

Site de prezentare pentru Relieff: rocă artificială, pereți decorativi, basoreliefuri și obiecte unicat sculptate manual.

## Ce conține

| Fișier | Rol |
|---|---|
| `index.html` | Acasă — hero, USP, piloni, segmente, valori, proces, CTA |
| `despre.html` | Povestea, arhetipul Creator, valorile, ce înseamnă roca artificială |
| `servicii.html` | Pereți decorativi, basorelief, obiecte unicat + matrice client–serviciu |
| `proces.html` | Cei 4 pași, principiile de lucru, ce influențează durata și costul |
| `contact.html` | Formular (neconectat încă) + date de contact de completat |
| `ghid.html` | Ghid pas cu pas pentru publicare pe GitHub + Vercel |
| `styles.css` | Toate stilurile, un singur fișier |
| `script.js` | Meniu mobil, animații de intrare, anul din footer |
| `vercel.json` | Configurare Vercel: site static, clean URLs, headere |
| `images/moodboard.png` | Imaginea de fundal (moodboard din brand book) |

## Publicare

Site static, fără build. Pe Vercel: **Framework Preset → Other**, Build Command gol, Output Directory gol.

Pașii completi, cu butoanele exacte: deschide `ghid.html`.

## De completat înainte de lansare

Caută în fișiere textul marcat cu chenar portocaliu (`class="todo"`):

- adresa de e-mail reală
- numărul de telefon
- adresa atelierului
- programul
- conturile de social media

Formularul din `contact.html` **nu trimite mesaje** — e pregătit vizual, dar fără serviciu conectat. Se activează cu Formspree sau Netlify Forms.
